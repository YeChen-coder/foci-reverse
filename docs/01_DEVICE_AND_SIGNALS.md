# 01. FOCI 设备与信号

## 1. 它不是脑电设备

FOCI 最容易被误解的地方，是 App 会显示“专注”“心流”“分心”“紧张”等心理状态，
看起来仿佛设备在读取思想。现有硬件资料和数据行为更支持下面这条链路：

```text
腰部/腹部的微小运动
        ↓
加速度传感器捕捉呼吸与身体运动
        ↓
设备固件进行滤波、特征提取和状态估计
        ↓
App 再结合个人校准、连续状态和产品逻辑
        ↓
专注/平静/分心/紧张/疲劳/心流等标签
```

因此，“专注”是模型的推断结果，不是直接物理量。类似地，体温计直接测温度，
而 FOCI 是先测运动，再从运动模式估计呼吸和状态。

产品资料可参考：

- <https://www.btmgroup.com/foci>
- <https://www.red-dot.org/project/foci-2-51768>
- <https://www.idesignawards.com/winners/zoom.php?eid=9-32108-20>

## 2. 电脑实际收到的是什么

当前抓到的主实时命令是 `27545`。普通实时消息至少有 21 字节。它不是标准的
三轴加速度 `X/Y/Z` 原始样本，而是一组已经由设备处理过的状态和内部指标。

桌面端显示的主要字段：

| 字段 | 当前理解 | 注意事项 |
|---|---|---|
| `state` | 设备当前离散状态 | 来自 `raw_state` 的低 5 位 |
| `focus_depth` | 专注深度内部评分 | 不是经过临床验证的心理量表 |
| `calm` | 平静/平衡相关评分 | App 内部名称与不同页面文案可能不同 |
| `signal` | 处理后信号幅度或质量相关量 | 不是原始加速度单位 |
| `signal_quality` | 有符号 16 位质量字段 | 实机中经常为 0，具体标定未知 |
| `mp_score` | mental performance score | 产品算法输出 |
| `tension_score` | 紧张相关评分 | 产品算法输出 |
| `focus_ev` | 专注事件或内部事件标志 | 精确语义尚未完全确认 |
| `mp_s_bit` | mental-performance 状态位 | 精确位定义未知 |
| `v_s` | 内部状态字段 | 精确标定未知 |
| `t_progress` | 训练/紧张进度类字段 | 超过 100 时客户端归零显示 |

这些名字来自归档 App 的类名、字段名和 UI 文案。字段位置是实机抓包确认的，
但“数值 70 到底等价于什么生理状态”并没有公开标定资料。

## 3. 状态映射

`raw_state` 的低 5 位是状态，高 3 位被客户端保留为 `data_type`。

| 数值 | 桌面标签 | 含义 |
|---:|---|---|
| 0 | `recalculating` | 重新计算 |
| 1 | `not_worn` | 未佩戴或无有效信号 |
| 2 | `adapting` | 正在适应呼吸/建立基线 |
| 3 | `in_motion` | 明显运动 |
| 4 | `distracted` | 分心 |
| 5 | `calm` | 平静 |
| 6 | `focused` | 专注 |
| 7 | `stressed` | 紧张/压力 |
| 9 | `fatigued` | 疲劳 |
| 10 | `flow` | 心流 |

状态 8 及其他未出现值没有强行命名。

## 4. 为什么要佩戴在腰部

呼吸会引起胸腹和身体姿态的周期性微小变化。腰部位置相对固定，既能观察这种周期变化，
也能观察走动、坐下、扭动等大动作。设备必须先区分“有效佩戴”“明显运动”和“可分析的
细微运动”，因此刚戴上时出现 `adapting`、移动时出现 `in_motion` 是合理的。

这也解释了几个使用现象：

- 放在桌上或充电时，页面可能显示 `not_worn`。
- 走动时，呼吸信号会被大动作淹没。
- 每个人的呼吸和动作模式不同，App 需要校准或学习。
- 短暂的一个数值不应被当成诊断；连续趋势比单点更有意义。

## 5. “震动提醒”在哪一层发生

电脑不是在检测到分心后临时发送“震一下”。抓包显示，App 把一组提醒开关写进设备配置。
FOCI 固件根据自己的实时状态和连续状态逻辑决定何时震动。

这很重要，因为：

- 关闭手机后，提醒仍可能由设备本身完成。
- 电脑只需同步提醒位和当前模式，不必复制完整分类模型。
- “1 次长震 / 2–5 次短震”是提醒类型的编码方式。
- App 文案提到连续状态（streak）和 1–3 分钟延迟，说明提醒并非每个单点状态都触发。

## 6. 可以相信到什么程度

可以较高置信度相信：

- 字节偏移、整数类型、状态代码和提醒位；
- 电脑与设备的收发行为；
- Deep Work 模式切换是否下发；
- 页面曲线确实来自设备实时流。

不应过度解释：

- 评分的临床或心理学意义；
- 状态模型的准确率；
- 某个内部字段的单位；
- FOCI 是否能在所有佩戴方式和人群上得到相同结果。

本项目是互操作与协议研究，不是医疗、心理或注意力诊断工具。
